# Studio Belíssima Mega Hair · prévia de site

> Prévia criada por Marcus Dantas como proposta. Não é o site oficial do negócio. Página com `noindex`.

Os dados do negócio (endereço, WhatsApp, horários e nota) estão no `index.html` e vieram do perfil público do Google Maps.

## Fotos

Fotos enviadas por Marcus Dantas em 14 de novembro de 2026 (formato WebP, já reduzidas para carregar rápido no celular):

- `img/hero.webp`: topo (cabelo longo acobreado)
- `img/espaco.webp`: seção "Sobre" (a profissional; recorte do banner com o logotipo, sem o texto)
- `img/trabalho-1.webp` a `img/trabalho-3.webp`: galeria (mechas, loiro liso e cachos; as fileiras repetem as 3 fotos)

Antes de mostrar a prévia ao negócio, confirme que as fotos são do próprio studio e que ele e as clientes autorizam o uso.

Na publicação da Vercel, as imagens são carregadas desta pasta do GitHub pelo jsDelivr (cdn.jsdelivr.net), liberado no `vercel.json`. A cópia no GitHub usa os caminhos locais `img/...`.
