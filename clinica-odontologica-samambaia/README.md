As duas fotos da recepção mostravam imagens na TV (um vídeo com pessoas e um anúncio de show com artistas). A tela foi borrada nas duas. As fotos dos consultórios são pequenas (555 x 450 px) e foram ampliadas, então ficam um pouco suaves; se a clínica tiver versões maiores, vale trocar.

Um aviso na recepção traz o nome "INNOVA". Confirme com a clínica se esse é o nome comercial.

Na publicação da Vercel, as imagens são carregadas desta pasta do GitHub pelo jsDelivr (cdn.jsdelivr.net), liberado no `vercel.json`. A cópia no GitHub usa os caminhos locais `img/...`.
